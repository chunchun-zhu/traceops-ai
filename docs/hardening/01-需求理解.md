## 目标与边界

可运行核心已有资料、任务、告警和维修复测闭环。本轮提高交付可复现性、数据恢复能力和人员责任可追溯性，模型部署仍由用户完成。

1. 每次 main 提交及 PR 自动执行跨平台测试、依赖检查、前端语法检查和容器冒烟。
2. 成套备份业务数据库与 LangGraph 检查点；校验失败拒绝恢复，恢复到新目录，保留任务、证据和历史事件。
3. 提供账号登录、会话失效、四种角色、账号启停和密码重置。标准由另一位人员独立审核，复测只接受已审核标准。
4. 默认本地演示保持可启动；账号模式显式启用，无默认密码。既有人工审批记录不能冒充登录身份审核。

## 验收

验证旧 Token 不能绕过账号模式、查看员不能写、操作员不能管理账号或资料、提交人不能自审、账号变更撤销会话、最后一个管理员不能停用或降级。以未完成排障的备份为起点，恢复后继续维修复测关闭；篡改文件和覆盖恢复必须被拒绝。

## 本轮不包含

真实模型与设备接入、OCR、企业 SSO、多租户和文档级 ACL、在线零停机恢复、生产运维托管。
