# 端到端评测需求

## 修订记录

| 版本 | 日期 | 摘要 |
|---|---|---|
| v1 | 2026-10-10 | 初版 |

已有检索冒烟仅 6 个模拟样本，缺少可由用户替换数据的整套闭环评测。提供独立 CLI 和受限 JSON 案例集，在临时 SQLite 中通过实际 API、LangGraph 与持久化流程运行，不写入用户当前业务库。

覆盖型号/版本过滤、故障码边界、资料或关系不足接管、检查推进、人工确认、维修复测、拒绝关闭、告警消除、重启和导出，以及逐条引用有效/拒绝/模型宕机路径。生成 JSON 和 Markdown，记录案例预期与实际结果、检索指标、数据版本、哈希和失败详情，未达通过阈值时 CLI 非零退出并接入 CI。

默认不调用真实模型，只用规则和明确标记的接口替身。真实标注集须显式提供资料/台账并关闭模拟初始化；用户最后部署模型后可以显式选择实际模型接口。模拟回归通过比例不能宣称诊断准确率或历史业务效果。
