## 实现

StandardInput 保存 title/model/minimum/maximum/reference_document_id/page/quote/source_start/approved_by。固定 MPa，数值有限且下限不超过上限。引用必须为有效、型号适用的手册；页码、原文与字符起点逐字校验，原文重复时须指定 source_start。记录文档标题/版本、审核时间、原文起止位置。审核人字段为人工记录，尚无账户身份认证。

标准不可编辑；修改范围须新增标准并停用旧记录。停用可逆。新通过复测必须提供 standard_id；minimum/maximum/reference_document_id 须与标准一致，型号适用、标准及资料有效、读数范围内，且读取时间在本轮维修后。读取与状态修改共享工作流锁。旧已关闭记录保留，旧未关闭会话通过时采用新规则。

每次复测冻结完整 standard_snapshot，后续停用不抹除历史依据。原文匹配只能证明引用存在，数字范围的含义、工况及适用条件仍须人员核验，系统没有自动抽取并证明数值。默认演示标准标为 is_demo=true，关闭 seed_demo 后不自动生成现场标准。MCP get_pressure_standards 只读返回有效标准。

通过 API POST /api/standards 新建，GET 查询，POST /api/standards/{id}/status 切换状态。页面在知识库维护，复测选择后自动带入范围，避免客户端自由扩大范围。
