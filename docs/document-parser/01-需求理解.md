# PDF OCR 与表格处理需求

目标：让设备手册中的文字层表格和扫描页进入现有检索、标准审核与后台任务流程，避免把识别结果直接当作可信压力标准。

用户约束：先交付可运行核心；所有代码提交到 traceops-ai；LLM、向量和 OCR 模型部署最后由用户完成。本轮不下载权重、不启用真实 OCR 推理。

验收范围：

1. 文字层 PDF 无需模型即可提取表格，保留行列、空格位、页码与页面坐标；表格作为完整切片检索。
2. 扫描页与混合 PDF 经可配置的识别服务处理；支持自动、仅文字层、全部 OCR 三种模式。
3. 保存原始 PDF、规范化页文本、块级字符范围、解析引擎与版本、置信度和警告；页面可展示原图核对。
4. 后台任务显示页进度，支持失败重试与协作取消；任一页失败不得导入半份资料。
5. 账号模式中，OCR 或表格来源的标准须另一位审核人员确认已核对原图，才能批准。
6. 备份恢复包含原始 PDF，原有文本导入与闭环测试继续通过。

不包含真实工业 OCR 效果评测、手写/复杂公式识别、跨页表格拼接、自动推断合并单元格数值、图表语义识别和分布式识别调度。
