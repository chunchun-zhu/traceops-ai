# 逐条引用定位设计

## 修订记录

| 版本 | 日期 | 摘要 |
|---|---|---|
| v1 | 2026-10-10 | 初版 |

`ModelExplanation` 只接受 claims，每项必须有 text 和 citations。每处 citation 包含 evidence_id、quote、start/end；禁止多余字段。位置为切片 text 内 Unicode 字符索引，半开区间。最多 8 条结论，每条 5 处引文，每处 2000 字符；短于 8 个非首尾空白字符的引文拒绝。

`grounding.validate_explanation` 核对切片集合、重复引用、逐字匹配和范围，再以文档读取函数核验有效版本、页码、页内原文。文档标题、型号、版本、页码及页内起止由服务端生成，模型不能提供。模型摘要与 evidence_ids 由验证后的条目派生，避免额外未引用摘要。

保存 `exact-quotes-v1` 与 `semantic_support=human_review_required`。工作流记录 anchored/rejected/unavailable/not_requested 状态及受控错误代码；不保存被拒绝的模型正文。引用失败保持规则检查，人可以主动转接管；有效资料或供气关系不足时沿用原自动接管分支。

页面逐条展示引文和来源，高亮采用 Array.from 字符数组以对应 Python Unicode 索引。历史旧摘要显示未逐条校验，不回填新认证。新文本切片保留源页原始空白；旧不可变切片若空白偏移无法核验则拒绝说明，使用真实新资料版本重新导入。

本模块只证明逐字引文和位置一致，不能证明结论被引文支持；不提供自动语义裁决、单位换算或现场压力标准审批。
